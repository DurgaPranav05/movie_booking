Online Movie Ticket Booking System

The Online Movie Ticket Booking System is a web-based application used to manage movies, customers and movie ticket bookings.

Technologies Used

HTML - For creating web pages.

CSS - For designing web pages.

JavaScript - For adding functionality.

Node.js - For backend development.

Express.js - For handling server requests.

MySQL Workbench - For database management.

Project Features

1. Add and manage movies.

2. Add and manage customers.

3. Book movie tickets.

4. Update and delete records.

5. View all database records.
